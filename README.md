# 💳 Plataforma Bancária Digital

Projeto acadêmico full stack inspirado em plataformas bancárias digitais modernas, integrando desenvolvimento web, modelagem de banco de dados e conceitos de engenharia de software.

---

## 🚀 Funcionalidades

- Interface bancária responsiva
- Páginas institucionais
- Estrutura de autenticação
- Recuperação de senha
- Visualização de produtos financeiros
- Modelagem relacional de banco de dados

---

## 🛠️ Tecnologias

### Frontend
- HTML5
- CSS3
- JavaScript

### Banco de Dados
- MySQL
- SQL

### Engenharia de Software
- Organização modular
- Documentação
- Estruturação de sistema
